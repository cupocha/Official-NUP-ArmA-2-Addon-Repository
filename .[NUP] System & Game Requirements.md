# System Requirements

**Minimum**

- Processor : i3-540
- Graphics Card : intel Hd 2000 Graphics or higher
- Ram : 2 GB DDR3
- Storage : 500 MB HDD free for NUP
- Game : ArmA 2 Combined Operations (Base+OA)

**Recommended**

- Processor : i5-4670s or higher
- Graphics Card : intel Hd 4600 Graphics or higher
- Ram : 4 GB DDR3
- Storage : 1 GB SSD free for AGUP 
- Game : ArmA 2 Combined Operations (Base+OA)
